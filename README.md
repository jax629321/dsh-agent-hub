# 智能体协作台 (dsh-agent-hub) · 插件包

DSH 内嵌的多智能体协作控制台:房间 / 群聊 / @派单 / 统筹大脑 / 逐轮审批 / 验收沉淀。
内置 TRD 后端随插件分发,自动安装依赖并启动,开箱即用。
v0.1 成员类型:OpenAI 兼容 API(纯 API 对接,无轮询依赖)。

## 安装(3 步)

### 1. 放入插件目录
把 `dsh-agent-hub` 文件夹复制到:

```
%USERPROFILE%\.dsh\profiles\node_modules\
```

### 2. 注册插件
编辑 `%USERPROFILE%\.dsh\profiles\web\cordis.patch.yml`,在 `- insert:` 下追加(已存在相同 id 则跳过):

```yaml
- insert:
    - id: dsh-agent-hub
      name: 'dsh-agent-hub'
```

### 3. 重启 DSH
重启后,左侧边栏底部出现「智能体协作台」按钮,点击即可使用。

## 前置条件

- **Python 3.10+**(可选但推荐):插件内置 TRD 后端,首次打开会自动创建虚拟环境并安装依赖(约 1-2 分钟)。若未安装 Python,控制台会显示首次安装指引,不会白屏。
- 无任何外部服务依赖:后端随插件分发,自动探测端口;本机已有后端时自动复用。

## 使用流程

1. 点侧栏「智能体协作台」→ 创建第一个群(无群时默认展示使用指引)。
2. 邀请成员:成员栏「邀请成员」→ 填 `base_url` / `api_key` / `model` → 点「添加成员」(OpenAI 兼容 API)。
3. 把某成员点「设为大脑」→ 输入目标 → 点「发给大脑」→ 大脑自主拆解、分工、监督、验收,按轮次推进。
4. 勾选「自动批准持续任务」可让大脑免人工逐轮确认;随时可「叫停」或逐轮「确认/否决」。
